# SWAT brand kit - start here

This is a review kit. Dave confirms the visual choices before public use.

1. Open the PDF for the visual overview. Brand-Guide.md is the editable client copy for Erinn and Claude.
2. The three detailed logo PNGs are the supplied originals. The simplified navy logo and wave icon are new imagegen design candidates with transparent backgrounds. The white-on-navy PNG is an opaque appearance reference, not a transparent white file.
3. For a shirt, send the simplified artwork to the embroidery vendor. Ask for one thread color, a machine stitch file, and a sample on the actual shirt. Start around 4 inches wide; the vendor chooses the final fit. No vector or stitch files are included.
4. Install the TTF fonts only if needed for document/design work. The website can self-host the files using assets/swat-brand.css, with font URLs relative to that CSS file. Keep the font licenses with the files.
5. Confirm activities, service area, contact details, photos, and rates before using the example website wording.
